# PDF Toolkit macOS v5 — Project Scope

- Native macOS application.
- UI is SwiftUI-first; AppKit/PDFKit is used only where native macOS PDF/file/printing capabilities are needed.
- Product name: PDF Toolkit.
- macOS 14+.
- System Light/Dark appearance.
- Home matches the supplied Figma direction while adding the requirement-driven PDF tools on the same screen.
- Required tools: Merge, Split, Rotate, Compress, PDF→JPG/PNG, JPG/PNG→PDF, Watermark, Protect.
- Stretch tools: Unlock (implemented for authorized passwords), OCR (Coming Soon).
- Canvas/editor: source PDF page + editable overlay text/stamp/image objects with live styling, move, resize and export.
- Premium: supplied Figma plan layout plus App Store Connect-backed StoreKit 2 products, verified entitlements, and centralized development override.
- Deferred: iCloud/Google Drive/Dropbox/OAuth/account backend.
